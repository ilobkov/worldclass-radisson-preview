Специальные привилегии членов клубов World Class и гостей отелей Radisson

Новые маршруты — привычный стиль жизни. Фитнес-клубы World Class и отели Radisson объединяют возможности для тех, кто ценит активный образ жизни, комфорт и качественный сервис.

Привилегия для гостей отелей Radisson

Скидка 15% на годовую карту в фитнес-клубы World Class.

Как получить

  • Скриншот письма с подтверждением бронирования в одном из отелей-участников.
  • Скриншот личного кабинета участника программы отелей Radisson.

Привилегия для членов клубов World Class

Скидка 15% на бронирование номеров с завтраком и без завтрака в отелях-участниках партнёрской программы.

При заселении в отель необходимо предоставить

Для владельца клубной карты World Class: скриншот карты лояльности и/или скриншот личного кабинета владельца клубной карты World Class.

Для ближайших родственников:

  • Копию свидетельства о заключении брака.
  • Копию свидетельства о рождении.
